Политика конфиденциальности приложения «Шлагбаум, быстрый вызов»

Дата последнего обновления: 21 октября 2026 года.

1. Кто ответственный за приложение

Автор приложения: [Олег], самозанятый.
Связаться можно по электронной почте: [komel19021991@yandex.ru].

2. Какие данные использует приложение

Вы сами вводите в приложение названия шлагбаумов, их адреса и номера телефонов для въезда и выезда. Приложение хранит эти сведения и ваши настройки (время до сброса звонка, выбранную SIM-карту) только в памяти вашего телефона.

3. Передача данных

Приложение не передаёт эти данные автору, не отправляет их в интернет и не передаёт третьим лицам. В приложении нет регистрации и учётных записей, рекламы, аналитики и сторонних сервисов, которые собирают данные. Приложение не запрашивает доступ в интернет. Ссылка на эту страницу открывается в вашем браузере.

4. Для чего нужны разрешения

  • Звонки — чтобы позвонить на номер шлагбаума по нажатию кнопки.
  • Управление вызовами — чтобы завершить звонок через заданное вами число секунд.
  • Доступ к состоянию телефона — чтобы показать список ваших SIM-карт и позвонить с выбранной.

Приложение использует эти разрешения только для перечисленных действий. Если вы откажете в доступе, часть функций (звонок, автоматический сброс, выбор SIM) работать не будет.

5. Срок хранения и удаление данных

Данные хранятся на телефоне, пока вы их не удалите. Удалить шлагбаум можно в приложении: «Изменить», затем «Удалить шлагбаум» и «Сохранить». Все данные удаляются также при удалении приложения или очистке его данных в настройках Android.

6. Дети

Приложение не предназначено для сбора сведений о детях и не собирает никаких персональных данных.

7. Изменения

Если политика изменится, новая версия появится на этой странице с новой датой.
